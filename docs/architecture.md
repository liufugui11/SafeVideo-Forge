# SafeVideo Forge 架构设计文档

## 1. 系统概述

SafeVideo Forge 是一款面向安全生产类视频号博主的**本地化自动化视频生产桌面工具**，采用 **Electron + Vue3 + Python FastAPI** 技术栈。

## 3. 核心组件

### 3.1 流水线引擎 (Pipeline Engine)

基于 **DAG（有向无环图）** 的任务调度引擎：

- **节点（Node）**：代表一个技能执行单元
- **边（Edge）**：代表数据流向和依赖关系
- **执行策略**：分层并行执行，同层节点可并发
- **状态管理**：支持断点续传、任务回滚、进度追踪

```python
# 流水线定义示例
pipeline = PipelineDefinition(name="自动生成视频")
pipeline.add_node(Node("script_gen", skill="文案生成器"))
pipeline.add_node(Node("script_split", skill="脚本拆分器"))
pipeline.add_node(Node("visual_gen", skill="画面生成器"))
pipeline.connect("script_gen", "script_split")
pipeline.connect("script_split", "visual_gen")
```

### 3.2 技能库系统 (SKII)

**插件化架构**，核心设计：

| 组件 | 说明 |
|------|------|
| `BaseSkill` | 技能抽象基类，定义执行接口 |
| `@skill` | 装饰器，注册技能元数据 |
| `SkillRegistry` | 技能注册表，动态加载/卸载 |
| `SkillContext` | 执行上下文，传递输入输出 |
| `SkillResult` | 执行结果，包含数据/错误/元数据 |

技能分类：
- `content` - 内容生成（文案、脚本）
- `visual` - 视觉生成（图像、视频）
- `audio` - 音频处理（TTS、BGM）
- `edit` - 视频编辑（合成、转场）
- `analyze` - 视频分析（解析、评估）
- `quality` - 质量检测（清晰度、专业度）
- `publish` - 发布分发
- `utility` - 通用工具

### 3.3 模型路由层 (Model Router)

**统一多模型接口**，智能路由策略：

```
用户请求 → 能力匹配 → 优先级排序 → 可用性检查 → 调用执行
```

| 能力 | 推荐模型 | 备选 |
|------|---------|------|
| 文本/对话 | DeepSeek-Chat | Kimi-128k |
| 脚本写作 | Kimi-128k | DeepSeek-Chat |
| 图像生成 | 万相-Wanx | DALL-E-3 |
| 视频生成 | 万相2.1-T2V | — |
| 推理/代码 | DeepSeek-Reasoner | — |

## 4. 数据流

### 4.1 视频生成流水线

```
[用户输入主题] 
    ↓
[文案生成器] ──→ 视频标题 + 完整文案 + 分镜建议
    ↓
[脚本拆分器] ──→ 结构化分镜脚本（场景/镜头/提示词）
    ↓
[画面提示词生成器] ──→ 统一风格的AI生成提示词
    ↓
[画面生成器] ──→ 图像/视频素材
    ↓
[语音合成器] ──→ 旁白音频
    ↓
[视频合成器] ──→ 合成视频（画面+音频+字幕+BGM）
    ↓
[质量检测器] ──→ 质量报告
    ↓
[成品输出]
```

### 4.2 视频解析流程

```
[上传视频]
    ↓
[提取元数据] ──→ 时长/分辨率/帧率/码率
    ↓
[关键帧采样] ──→ 色彩/亮度/构图分析
    ↓
[音频分析] ──→ 语速/语气/音调
    ↓
[AI深度分析] ──→ 语言风格/画面风格/传播潜力
    ↓
[结构化报告]
```

## 5. 前端架构

### 5.1 技术栈

| 技术 | 用途 |
|------|------|
| Electron 28+ | 跨平台桌面壳 |

### 5.2 页面结构

```

├── Dashboard (工作台)
├── Pipeline (流水线编排)
├── Skills (技能库)
├── Analyzer (视频解析)

└── Settings (设置)
```

### 6.1 实体关系


| 表名 | 用途 |
|------|------|
| `projects` | 项目信息 |
| `pipeline_runs` | 流水线执行记录 |
| `skill_logs` | 技能执行日志 |
| `media_assets` | 媒体资源管理 |

## 7. 安全与隐私

- **本地优先**：所有数据处理在本地完成
- **API Key加密**：敏感配置存储加密
- **沙箱隔离**：Electron渲染进程沙箱化
- **无遥测**：不上传用户数据

## 8. 扩展性设计

### 8.1 技能扩展

用户可通过以下方式扩展技能：
1. 在 `skills/` 目录创建新的Python模块
2. 继承 `BaseSkill` 类
3. 使用 `@skill` 装饰器注册
4. 系统自动加载

### 8.2 模型扩展

在 `ModelRouter` 中添加新的 `ModelConfig` 即可支持新模型。

## 9. 性能优化

| 策略 | 实现 |
|------|------|
| 异步执行 | 所有I/O操作使用async/await |
| 并行处理 | 流水线同层节点并行执行 |
| 缓存机制 | AI生成结果本地缓存 |
| 增量更新 | 仅重新执行变更节点 |
| GPU加速 | 可选CUDA加速视频处理 |
